### 🚀 What I'm Working On

**Suthiram AI (Amaippu Internship)**
An AI pipeline (Python, Flask, Ollama) that turns text prompts and images into valid `.suthras` parametric furniture files — integrating **Llama 3.1** for text generation and **LLaVA** for image-to-furniture generation, backed by a RAG dataset of reference furniture files, with a Flask web UI for generation, review, and approval.
